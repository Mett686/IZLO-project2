# IZLO Project 2 – SMT Solver Modeling

Second project for the **IZLO (Logical Foundations of Computer Science)** course, written in SMT-LIB.

## Overview
Formalization and logical modeling of a constraint satisfaction and optimization problem using first-order logic theories in the **SMT-LIB v2** format.

## Usage
Run the model using an SMT solver such as **Z3** or **CVC5**:
```bash
z3 -smt2 model.smt2
```
